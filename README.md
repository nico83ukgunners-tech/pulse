# Pulse

Appli web de musique personnelle (installable sur l'écran d'accueil de l'iPhone).

- Importe tes propres fichiers audio depuis l'app Fichiers.
- Pochettes et titres lus dans les tags ID3.
- Groupes personnalisés (Sport, Running, Muscu, Chill, Soirée…), un morceau peut être dans plusieurs groupes.
- Lecture en arrière-plan et commandes sur l'écran verrouillé (Media Session).
- Fonctionne hors connexion : les morceaux sont stockés sur l'appareil (IndexedDB).

Aucune musique n'est incluse dans ce dépôt.

## Lancer en local
    python3 -m http.server 8000
puis ouvrir http://localhost:8000

## Publier (GitHub Pages)
